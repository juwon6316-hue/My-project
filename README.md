# 아침·저녁 기도문

매일 아침 일어났을 때, 저녁에 잠들기 전에 열어 보는 간단한 기도문 사이트입니다.

- 접속한 시간에 따라 아침/저녁 기도가 자동으로 열립니다 (직접 전환도 가능).
- 글자 크기 조절(설정은 기기에 저장됩니다).
- 기도문 수정: `prayers.js` 파일의 글을 원하는 내용으로 바꾸세요.

## 실행
`index.html`을 브라우저로 열면 됩니다. 또는 `python3 -m http.server` 후 http://localhost:8000
GitHub Pages로 배포하면 휴대폰에서도 바로 열 수 있습니다.
