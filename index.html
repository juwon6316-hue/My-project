이 기기의 브라우저에만 저장돼요.

이번 주 설교 말씀 필기를 적으면, 그 내용에 맞는 묵상 기도문을 AI가 만들어 줘요.

AI 연결 설정 (처음 한 번)

무료 Google Gemini API 키가 필요해요. aistudio.google.com 에서 구글 계정으로 로그인 → "Get API key" → 키 만들기. 키는 이 기기의 브라우저에만 저장되고, 설교 필기는 기도문을 만들 때 Google로 전송돼요. (무료 사용분은 서비스 개선에 쓰일 수 있으니 이름·연락처 같은 개인 정보는 적지 마세요.)
